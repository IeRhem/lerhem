# leRhem — Portfolio

Personal portfolio for Rhema Joseph (leRhem), a freelance full-stack
developer based in Taraba, Nigeria.

## About

Built to show potential clients and employers what I build and how to get
in touch — services, selected projects, and a way to start a conversation.

## Tech Stack

- [Next.js](https://nextjs.org) (App Router)
- TypeScript
- Tailwind CSS v4
- No component library — all components hand-built

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view it locally.

## Scripts

| Command         | Description                  |
| ---------------- | ----------------------------- |
| `pnpm dev`      | Start local dev server        |
| `pnpm build`    | Create a production build     |
| `pnpm start`    | Run the production build      |
| `pnpm lint`     | Lint the codebase             |

## Project Structure

```
/app              # routes, layout, page composition
/components
  /ui             # hand-built base components
  /sections       # page sections (Hero, Services, Selected Projects, etc.)
/lib              # shared utilities
```

See `AGENTS.md` for conventions and content rules followed in this repo.
